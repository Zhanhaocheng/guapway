下午被一条 TypeScript 报错拦住。表面是 `Type X is not assignable to type Y`，修了两处类型定义之后，错误只是换了个位置。

## 先别改类型

停下来看 import 图。问题不在类型是否足够宽，而在一个工具函数同时被服务端和客户端引用，边界被悄悄打穿了。

把函数拆开之后，类型错误自己消失了。

## 一条可以复用的规则

```txt
报错在类型层，先检查模块边界，再改类型。
```

学习日志不一定要写成教程。把踩坑时真正生效的那条规则留下来，就够用了。
